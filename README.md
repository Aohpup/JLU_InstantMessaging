## P1 登录与菜单

新库首次启动可使用下方演示账号，已有库读取之前保存的数据；若从空平台练习注册，可用 `jlu_im.exe --empty` 启动，然后选择“2 注册并开通首项服务”，填入姓名、生日、所在地、昵称和两次密码。注册成功后记录显示的对外号码，再选择“1 登录”。

登录后可查看资料、开通其他服务、确认切换、修改昵称和绑定本人微信／QQ。输入 0 返回；登录菜单的 0 统一注销，主菜单的 0 保存并退出。正常模式可用主菜单 4 或登录菜单 10 主动保存，注销不保存；内存模式不显示保存入口。--empty 模式没有预置账号。本人 QQ 和微信在同一会话均登录，或两者均曾用密码成功登录后，可以绑定；注销清除当前会话，但不清除本次程序运行内的密码登录记录。

操作结束后按任意键继续。Ctrl+C 在无选择时不会退出；选中文字时可正常复制，正常退出使用主菜单 0。密码仍显示星号。

密码处理已按课设需求简化：用私有字符串在内存中保存测试密码，通过 == 比较登录输入；不使用密码派生或 BCrypt。该演示保存的是明文，仅用于虚构课堂账号；正常模式保存时会将凭据写入 SQLite。密码长度、字符检查、星号和重输保持原行为。当前 Windows 依赖来自控制台输入。

## 代码注释约定

代码注释规范（后续开发持续遵守）：注释统一使用简体中文，简洁明了。优先在头文件的类、函数声明或重要成员定义处说明职责、用途及必要的参数、返回值和约束。实现文件已有清楚说明时避免重复；仅在关键实现逻辑或没有头文件的函数定义处补充必要注释。不逐行翻译代码；新增或修改代码时同步维护注释，确保与实际行为一致。函数说明使用普通 `//` 并紧贴对应声明；多个函数分别说明，不使用 `@brief`、`@param` 等标签。为便于悬浮阅读，可将实现处的接口说明移至头文件，关键实现逻辑仍在原处注释。

## P5 第一批：Socket 最小链路（已完成）

新增 TcpPeerLJY 和 p5_socket_demo，可在两个终端实际双向发送中文；与原菜单及 GUI 分开运行，不使用数据库。

```powershell
cmake --preset local-debug
cmake --build --preset local-debug --target p5_socket_demo
# 终端 A
.\build\debug\bin\p5_socket_demo.exe listen 127.0.0.1 27015 "你好，我是 A。"
# 终端 B
.\build\debug\bin\p5_socket_demo.exe connect 127.0.0.1 27015 "你好，我是 B。"
```

以上从项目根目录运行，两端 PATH 需包含 C:/mingw64/bin。每端本批只发送一段短文字，接收完成后退出；连续消息协议和后台线程属于第二批。4 个关键 Socket 场景通过，两套工具链编译通过，正式数据库保持不变。
