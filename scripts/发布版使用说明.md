# JLU 即时通信 · P4 发布版

Windows x64，Qt 6.8.3 / MinGW 13.1 Release。无需安装 Qt、编译器、SQLite 服务或 MySQL。

1. 解压整个文件夹到可写位置（例如桌面或 D 盘），不要单独取出 exe。
2. 双击 jlu_im_gui.exe 打开图形端；jlu_im.exe 是终端入口。
3. 首次正常启动会创建同目录 data/jlu_im.db 并写入演示数据。演示 QQ：10001，密码 DemoOnly123!。已有数据库恢复原记录，启动后仍需登录。
4. 修改先进入内存，点“保存数据”或正常关闭才写入数据库。先保存并关闭一个入口，再打开另一个，二者共用同目录数据库。
5. 备份时先关闭程序，再复制整个 data 文件夹。这个发布包没有附带用户数据库。

在本目录 PowerShell 运行：

```powershell
.\jlu_im_gui.exe --demo
.\jlu_im_gui.exe --empty
.\jlu_im_gui.exe --database '.\练习库.db'
.\jlu_im.exe --help
```

--demo 仅在内存中载入演示数据，--empty 是空平台内存练习，二者关闭不保存。--database 使用指定库，相对路径按当前工作目录解释；默认库始终在 exe 旁的 data，移动整个文件夹仍能找到它。

开发版仍用项目 data/jlu_im.db。如需使用原项目数据，关闭两个入口后将原库复制到本目录 data/jlu_im.db，或通过 --database 指向原文件；复制前保留已有库备份。

账号、好友申请与推荐、群成员权限、子群和模式切换均可使用。侧栏“消息”是 P5 预留页，当前没有联网聊天，也没有多人实时同步。

答辩建议：登录 QQ 10001 → 修改资料/头像并保存 → 向 QQ 10005 发送好友申请 → 注销换 10005 同意 → 换回 10001 查看好友 → 群聊选 1001 查看成员和权限反馈 → 子群与模式创建子群并切换模式 → 保存关闭 → 用终端查看同一库 → 再打开图形端。
