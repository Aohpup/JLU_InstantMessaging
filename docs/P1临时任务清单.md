## 框架阅读顺序

先读 domain/PersonLJY.h 与 domain/ServiceAccountLJY.h，再读 services/SocialServiceLJY.h 和三个派生类，最后读 src/main.cpp。LJY 表示作者 Li Jiaye；用户数量不影响类文件数量。

头文件描述类型的属性和接口；.cpp 实现成员函数；三个枚举文件只描述有限选项。Person 不保存另一份账号副本，ServiceAccount 使用 personId 建立关联，现由 PlatformLJY 统一管理，AccountServiceLJY 负责写入前的校验。

当前 main 仅创建平台、会话和菜单。继续阅读 SessionManagerLJY.h、ConsoleAppLJY.h，再运行菜单体验完整流程；底层账号规则仍由 AccountServiceLJY 负责。
