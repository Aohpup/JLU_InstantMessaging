## 2 主要代码变化与阅读

1. [MessagesPageLJY.cpp](../src/gui/MessagesPageLJY.cpp)：连接面板只显示本机地址与端口，beginConnection 使用回环地址，删除双机配置分支。
2. [GroupMessagesPageLJY.cpp](../src/gui/GroupMessagesPageLJY.cpp)：群设置与后台群加入统一使用本机端口，不再解析外部 IP；正常模式继续要求持久历史。
3. [GroupChatClientLJY.cpp](../src/network/GroupChatClientLJY.cpp)：删除 UDP 发现；先连接/启动本机服务。要求持久历史时不得退回内存房间，内存练习才允许本机窗口开房。
4. [GroupChatHostLJY.cpp](../src/network/GroupChatHostLJY.cpp)、[main_group_server.cpp](../src/network/main_group_server.cpp)：只监听本机，删除 --lan 选项。
5. 现有测试改用精简后的接口，删除仅对应局域网发现/IP 校验的用例，保留本机连接与历史用例，并检查旧双机配置不会恢复外部连接入口。

账号、好友、群权限、SQLite 表结构与用户聊天数据没有改动；独立类文件整理不属于本次 9A，继续列在报告前待办。
