## 2 日常入口与数据约定

推荐从文件管理器打开项目内 `dist/JLU_InstantMessaging/jlu_im_gui.exe`；默认库为 `dist/JLU_InstantMessaging/data/jlu_im.db`。完整路径和任意 PowerShell 目录启动命令已写入 [P5 使用说明](P5使用与代码说明.md)。

- `build/gui-release/bin/jlu_im_gui.exe` 默认使用其自己的 `data/jlu_im.db`。
- 当前 Debug 预设使用项目根目录 `data/jlu_im.db`。
- 需要读取已有旧库时，关闭使用它的程序，再用 `--database` 明确指定；本次没有把任何旧聊天库搬动或合并。
- 本机独立群服务的日志与成员文件位于 `%LOCALAPPDATA%/JLU_InstantMessaging/group-server`，与客户端库分开。
- `--demo` / `--empty` 是内存练习，不能用来验证客户端重启恢复。

不同入口看到不同记录，应先看界面底部的实际数据库路径；不能直接据此判断记录丢失。客户端库与群服务日志均需在对应程序停止后备份，复制或覆盖数据库不等于合并记录。
