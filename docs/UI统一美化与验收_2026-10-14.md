# 全界面统一美化与验收

日期：2026-10-14。用户已授权统一美化全部 UI，保留不满意后回退的选择。本轮属于现有 Qt 界面改进，不启动新业务阶段。

## 1 这轮的设计原则

保持浅绿主题、微软雅黑、左侧导航和右侧工作区，使用统一的尺寸与状态规则。以易读、同类操作一致、功能分级明确为目标，没有引入新的主题框架或外部 UI 依赖。

- 背景为浅灰绿，侧栏更深一层；乳白卡片有细边、顶部高光和柔和投影，文字不模糊。
- 正文和按钮使用常规字重，标题与头像加粗。卡片标题用细分隔线，不再叠加左侧色条。
- 绿色表示主要操作；账号资料和密码编辑保留用户指定珊瑚红；退出、删除等操作使用浅红描边。
- 悬停、按下、焦点、选中、禁用都有一致反馈。边框宽度不随状态跳变。
- 内容按 4/8 像素的间距节奏排列，常规行高 36 像素；不是把所有用途的控件机械设成同一个大小。

## 2 按钮和表单尺寸

| 同类区域 | 当前尺寸（逻辑像素） |
| --- | --- |
| 顶部 QQ、微信、微博、保存、注销 | 88×36 |
| 资料、昵称、密码及对应取消 | 120×36 |
| 好友发消息、备注、删除 | 88×36 |
| 群进入/加入/退出、子群三个操作 | 88×36 |
| 查询、刷新、邀请、模式切换 | 112×36 |
| 同意/拒绝、保存/取消等成对确认 | 同组 112×36 |
| 私聊/群聊设置、发送、复制 IP | 同组 96×36 |
| QQ 绑定/解绑 | 80×32，适配表格行 |
| 登录/注册提交 | 等高 44，跟随表单宽度 |
| 内置确认卡片 | 同组等宽、等高 40，按最长按钮文案留足宽度 |
| 普通输入、下拉和端口框 | 等高 36 |

头像色点、三点菜单、消息展开、侧栏导航和身份卡属于不同用途，保留专用尺寸。按钮尺寸集中在 `ActionStyleLJY.h` 的简单辅助函数中维护；颜色与字体集中在 `theme.qss`，不再靠每个页面各写一套近似样式。

## 3 页面和操作层级

侧栏顺序是“消息、群管理、好友列表、我的账号”。顶部显示当前页面路径、三个服务及保存注销。侧栏群管理负责成员权限，消息页的“私聊 / 群聊”负责实时通信，避免两个“群聊”入口含义不清。

| 页面 | 本轮变化 |
| --- | --- |
| 登录与注册 | 对齐标签和输入框，当前表单决定卡片高度；保持宽屏缩放，登录不为注册表单预留无用空白，小窗口注册内容可以滚动到提交按钮 |
| 我的账号 | 三卡片统一标题、间距与操作尺寸；已全部开通服务时收起无用的开通输入区；资料和密码继续在页面内编辑 |
| 好友 | 添加、列表、详情保持清晰分区，三个快捷操作同排等尺寸；查询与申请使用同一页签风格 |
| 群管理 | 查找/刷新在搜索卡片；进入群聊放到当前群资料旁；成员、申请邀请、子群模式分三级操作，表格取消密集网格线 |
| 私聊与群聊 | 两类会话卡片起点、标题和输入区域统一，设置和发送尺寸一致；更多设置在小窗口分行布局 |
| 聊天好友列表 | 窗口缩小时重新布局行宽，昵称可省略，头像和三点菜单完整保留，不依靠横向滚动找入口 |
| 固定反馈与确认 | 保留底部错误条和震动、普通黑字提示；继续使用应用内确认卡片与同尺寸按钮 |

业务接口、数据库表、群聊协议和终端界面没有改动。选择群即自动加入、发送快捷键、历史分页、申请审批与保存流程继续保留。

## 5 验收与发现的问题

本轮对受影响图形功能运行 25 项 CTest，全部通过：账号、好友、群、子群、申请、字体和错误震动、三服务私聊及群聊、历史、连接和生命周期。没有为纯视觉变化反复运行未改动的核心业务测试。

新验收 `p5_ui_design` 检查同类按钮实际尺寸、900×600 窗口大小、可见按钮文字、横向溢出、登录和注册提交入口，生成实际截图。旧好友按钮测试中 34 像素高度同步改为本轮已批准的 36 像素，仍验证同排和等尺寸。

截图额外发现窄窗口的好友行仍保留旧宽度，三点菜单被裁切。增加实际几何断言后先复现失败，再通过 QListView::Adjust 修复；相关 2 项复验通过。最后微调登录卡片高度后，对登录注册、字体及全部页面布局的 5 项复验通过。验收摘要和最后复验日志保存在截图目录。

测试使用 offscreen Qt 和隔离数据库，不能当成人工逐项点击或多台实体电脑验收。Release 与便携包同步，发布核对记录在同目录；正式数据库未用于 UI 验收。

## 6 回退方式

美化前的源码、相关文档和完整便携程序已保存到：

`backups/UI美化前_20261014_212517/`

- `source_before.zip`：本轮前的 UI 源码及相关文档。
- `portable_before.zip`：包含此前群聊和历史分页修复的完整旧版便携程序。
- `change_manifest.json`：本轮修改和新增文件清单。

如果不满意，可以要求“回退这轮 UI 美化”，也可以指定只回退登录、按钮、菜单或某个页面。恢复时按清单处理本轮改动并重新构建，保留数据库和之后独立开发的内容；不把整个工程盲目覆盖成旧版本。

## 7 代码阅读

先看 `theme.qss` 的分区规则，再看 `ActionStyleLJY.h` 的尺寸表；随后看 MainWindow 的导航/顶部区域，以及各页面构造函数中的布局。业务函数和网络模块不需要因本轮外观调整重新阅读。
