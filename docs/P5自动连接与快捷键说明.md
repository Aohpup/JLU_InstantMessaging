# P5 自动连接与快捷键说明

更新日期：2026-10-14。本次为已完成 P5 的交互调整，P6 未启动。

## 使用方法

1. 本机两个窗口：使用独立数据库，登录同一服务的两个好友账号，各自选中对方，选择“本机演示”，双方点击“开始聊天”。默认 127.0.0.1:27015，端口可在更多设置修改。
2. 两台电脑：双方选择“两台电脑”；更多设置会显示自动角色。等待方复制本机实际局域网 IPv4 给主动方，主动方填写“等待方 IP”并保存。端口保持一致，双方点击开始聊天。
3. Enter 发送；Shift+Enter、Ctrl+Enter 换行。未连接时允许写草稿，按 Enter 只提示先连接，文字保留。
4. 设置在聊天内容区内展开，不弹系统窗口；保存或取消后返回聊天，后台仍接收消息。在线修改端口或 IP 下次生效。连接成功时收起连接区；断开后显示“重新连接”。

## 自动分工和等待

数字账号按数值大小决定，小号等待、大号主动连接；有字母的账号按固定字符串顺序比较，双方得到一致且互补的结果。因此 QQ、微信、微博共用同一套入口，无需用户选择监听或连接角色。

主动方先开始时，收到“连接被拒绝”或连通前超时后，2.5 秒再试，累计等待最多 60 秒；等待期间提供取消。等待方可持续等待。账号握手失败、端口占用、收发错误不重试，使用原红色反馈。已连通后断线需手动点重新连接，不自动重发任何旧消息。

两机模式等待方监听 0.0.0.0；网卡下拉框用于选择和复制发给对方的地址，不是切换监听网卡。请选择两台电脑可互通的真实局域网地址，不要使用虚拟网卡地址。此模式不提供公网中转或账号同步。

## 配置与代码阅读

正常模式把配置保存在数据库路径追加 `.connection.ini` 的文件中，例如 `data/jlu_im.db.connection.ini`；本机、两机端口分别存储，两机另存等待方 IP。内存模式使用 Qt 当前应用配置目录下的 connection.ini。配置不进入 SQLite，也不包含密码。发布脚本排除使用者的连接配置文件。

阅读顺序：

1. `MessagesPageLJY.h`：连接控件、当前尝试快照、重试计时器，以及简体中文注释。
2. `MessagesPageLJY.cpp` 的 `shouldListen`：账号比较；`beginConnection`：确定角色与本次地址端口。
3. `startConnection`：调用已有 TcpPeer；`pollEvents`：区分普通等待和真正错误，安排重试；`stopConnection`：先取消重试，再回收连接。
4. `loadConnectionFields` / `saveConnectionSettings`：QSettings 读取和保存两个模式的配置；已经开始的连接使用快照，表单改动不影响它。
5. `eventFilter`：处理 Enter 和带修饰键的换行；`updateControls`：连接状态及小窗口设置区切换。

CMake 增加 Qt Network 链接，仅用它读取网卡和校验 IP，消息仍通过原 Winsock / TcpPeer 模块传输。协议、业务模型、终端及 SQLite 消息表未改动。
