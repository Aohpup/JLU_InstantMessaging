## 功能与权限

登录后选择 **9 群管理**，显示我的群列表后，先输入有效群号，再选择该群的操作。1 切换群聊，0 返回主菜单。非成员也可选群以申请或接受邀请。输入群号时按当前服务查找，QQ 的 1001 与微信的 1001 互不影响。成员操作中输入对方的服务号码，不输入内部编号。

| 选项 | 操作 | 规则 |
| --- | --- | --- |
| 1、2 | 切换群聊、群资料与成员 | 我的群列表在选群时自动显示 |
| 3 | 申请入群 | QQ/微博的非成员提交，等待群主或管理员审批 |
| 4 | 邀请入群 | 微信现有成员邀请同服务的非成员，等待对方确认 |
| 5 | 查看申请与邀请 | 显示本人相关或当前可审批的请求，包含处理状态 |
| 6 | 处理申请或邀请 | 输入请求编号，再选同意、拒绝或返回；邀请只能由被邀请人处理 |
| 7 | 退出群 | 群主须先转让；其他成员可退出 |
| 8 | 移除成员 | QQ 群主须先撤销目标管理员身份才能移除，管理员只能踢普通成员；微信仅群主可踢人 |
| 9 | 设置或取消管理员 | 仅 QQ 风格群的群主可操作，目标不能是群主 |
| 10 | 转让群主 | 仅群主可转让给同群其他成员，原群主成为普通成员 |
| 0 | 返回 | 返回主菜单 |

申请与邀请只创建待处理记录，接受后才加入成员列表。同群同一目标不允许重复的同种待处理请求。审批检查当前权限，管理员被撤销后不能继续审批。邀请人退群或被踢后，其待处理邀请失效，再次入群不会恢复旧邀请。转让时清除新旧群主的管理员标记。

所有修改都有确认步骤，取消或输入结束不改变成员名单。无效群号在选群时拒绝；执行者权限和目标账号在确认前检查。移除成员或任免管理员前先展示成员信息，移除自己立即拒绝。请求只展示和处理当前群的相关记录。业务失败后保留菜单入口，真实控制台沿用“>>>按任意键继续”。密码星号和 Ctrl+C 输入实现保持原行为。

## 手动检查

运行 `build/debug/bin/jlu_im.exe`，默认已有演示数据，所有演示账号密码均为 `DemoOnly123!`。每次重新启动都会重置演示数据。

QQ 申请与审批：

1. 用 C 的 QQ **10003** 登录，进入 9 群管理。C 初始已在 1001 群，先输入群号 1001，再选 7 退出并确认。成功后返回选群入口。
2. 重新选择 1001，选 3 申请入群并确认，记住显示的请求编号；选 5 可见“待处理”。
3. 返回主菜单并注销，用管理员 B 的 QQ **10002** 登录，选 9 → 输入群号 1001 → 6，输入请求编号，选 1 同意。
4. 查询 1001 成员，C 已成为普通成员。用 A 的 QQ **10001** 可设置/取消 C 的管理员；B 不能踢另一名管理员。
5. A 可选 10 将群主转给 B；转让后 A 成为普通成员，可以选 7 退出。

微信邀请与失效：

1. 用 D 的微信 **wx_20003** 登录，选 9 → 输入群号 **1002** → 4，邀请 F **wx_20004**，确认并记录请求编号。
2. D 在 F 接受前退出 1002。F 登录后选 9 → 输入群号 1002 → 5，会看到该邀请“已失效”，不能再接受。
3. A 的微信 **wx_20001** 仍在 1002，可重新邀请 F。F 选定 1002 后，在 6 中选择接受后入群；选择拒绝则不入群。
4. 微信 1002 初始群主为 B **wx_20002**。A 可邀请，但不能踢人；B 可踢人或转让群主，不能设置管理员。

## 代码阅读路径

1. [GroupRequestLJY.h](../src/domain/GroupRequestLJY.h)：一份申请/邀请记录，保存种类、双方号码、群号和状态。
2. [GroupManagerLJY.h](../src/services/GroupManagerLJY.h) 与 [实现](../src/services/GroupManagerLJY.cpp)：提交请求、处理请求、修改成员；先检查，再修改。
3. [SessionManagerLJY.h](../src/services/SessionManagerLJY.h)：由当前登录账号确定操作者，将菜单输入的号码解析为当前服务账号。
4. [ConsoleAppLJY.cpp](../src/ui/ConsoleAppLJY.cpp)：groupMenu 展示选项，groupAction 收集输入及确认，再调用会话接口。

请求由 Platform 的 map 保存，成员仍由 Group 的 vector 保存。请求使用“服务＋群号/账号号码”关联，这些号码在当前项目中不会改变。退群与踢人共用 removeMember，不增加审批框架、工厂或额外校验层。新增一个类和两个枚举，截至本次交互修正，正式源码共 22 个类、7 个枚举（新增 GroupOperationLJY 表示群操作）；沿用 int、简体中文普通 // 注释及头文件说明。
